# basic-portfolio-website


A clean, semantic, and responsive single-page portfolio built using pure HTML5.

## Project Structure
- `index.html`: The main entry point containing the About, Skills, and Contact sections.
- `images/`: Folder containing all visual assets.
- `README.md`: Project documentation.

## Features
- Full HTML5 Semantic tags for SEO and Accessibility.
- Working internal navigation links.
- Responsive contact form.
- Optimized for fast loading with no external libraries.
